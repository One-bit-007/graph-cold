## 3. Table 4 替换数字（「no aggregate cost」→ TOST 非劣效 + Δ/CI）

原稿 Table 4 的 Cost 列以「none」声称软保留无聚合代价，推断不严谨。最终协议下的替换声明（#4 soft vs #3 hard，宏均值）：

| 数据集 | 噪声率 | Δ Macro-F1 | TOST δ=0.01 | 逐类护栏最差回退 |
|---|---:|---:|:--:|---:|
| CESNET | 0.4 / 0.6 / 0.8 | +0.024 / +0.031 / +0.031 | 全通过（p≤0.0001） | -0.029 / -0.036 / -0.008 |
| CICIDS | 0.4 / 0.6 / 0.8 | +0.052 / +0.062 / +0.055 | 全通过（p≤0.012） | 0.000 / 0.000 / 0.000 |
| UNSW | 0.4 / 0.6 / 0.8 | +0.014 / +0.023 / +0.030 | 全通过（p<0.0001） | -0.005 / -0.000 / -0.001 |

- 9/9 条件同时通过 TOST 与逐类护栏（护栏阈值 0.05，最差为 CESNET 类 21 @ rate 0.6 的 -0.036）；
- 宏均值差**全部为正**——替换措辞不应是「无代价」，而是「未检测到聚合代价；聚合宏均值一致为正（+0.014~+0.062）」；
- 配套披露：δ=0.01 的预注册局限性（11 类下最坏情形 ≈ 单类 0.11 F1 退化）已由逐类护栏直接覆盖，护栏全部通过，故「聚合非劣效且无可检测类级代价」成立。
- 数据出处：`results/p5_factor_ablation_full.csv`（宏均值）、`results/p5_perclass_guard.csv`（逐类，伴随重算，预测与主结果一致至 n_jobs 浮点噪声 ~1e-4，远低于护栏阈值）。
