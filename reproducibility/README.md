# Graph-CoLD Reproducibility Package

This package documents how the submission artifacts are produced from the
tracked, frozen experimental outputs. It does not retrain models, rerun the
experimental matrix, or modify model code.

## Authoritative result source

The submission results (main performance, high-noise summary, ablation, and
statistical-test tables) are generated by the P2f clean-deduplication protocol.
See `reproducibility/README_realdata.md` and `reports/p2f_tighten.md` for the
exact reproduction commands. The external anchor results (Confident Learning
and full Co-Teaching) are frozen in `results/p5_external_baselines.csv` with
Holm-corrected tests in `tables/table_p5_external_tests.csv`.

Do **not** regenerate submission numbers with the earlier D5/D9 scripts; they
predate the leakage audit and may produce different numbers. `run_all.sh` and
the `run_d6_*`/`run_d7_*`/`run_d8_*`/`run_d9_*` PowerShell wrappers target that
earlier pipeline and are retained for audit history only.

## Manuscript

The submission manuscript is `paper/graph_cold_cas_final.tex`, compiled with
two `pdflatex` passes from the `paper/` directory to
`paper/graph_cold_cas_final.pdf`. Supporting statements for the submission
system (cover letter, highlights, declarations, data availability, CRediT) live
under `paper/submission/`.

## Traceability note

All numeric claims in the manuscript are taken from `results/`, `tables/`, and
the P2d/P2e/P2f/P5 audit reports under `reports/`. MALTLS-22 and OpTC are not
part of the formal evaluation package. Raw datasets are not committed; see
`README_realdata.md` for the expected dataset layout and the
`GRAPHCOLD_DATA_ROOT` environment variable.
